{{- /* Usage: {{ partial "photo-gallery.html" . }} (. = a Page) Renders a grid of downloadable photos from the page's `photos` front matter. Each entry becomes one tile per real file present — `full` (the original) and/or `square` (a pre-cropped square version) — so a press person on deadline clicks straight through to the exact file they want. No separate "which resolution" links to parse: the tile *is* the download. The on-page preview shown in the grid is generated on the fly by Hugo's image processing, so there's no separate hand-resized file to maintain just for display — only the two real deliverables need to exist. Front matter shape: photos: - label: "Studio headshot" full: "photo.jpg" square: "photo-square.jpg" # omit if no crop exists alt: "Description" */ -}} {{- with .Params.photos -}} {{- $page := $ }} {{- $versions := slice (dict "field" "full" "name" "Full size") (dict "field" "square" "name" "Square crop") }}
{{- range . }} {{- $photo := . }} {{- range $versions }} {{- $versionName := .name }} {{- $filename := index $photo .field }} {{- with $filename }} {{- $resource := $page.Resources.GetMatch $filename }} {{- if $resource }} {{- $preview := $resource.Fill "480x480 Center q80" }} {{- end }} {{- end }} {{- end }} {{- end }}
{{- end -}}
